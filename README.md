# Student Records

INFO 6150 Assignment 3: a student directory built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Features

- Starts with one student record.
- Add records one at a time; student, teacher, and email numbers increment with each record.
- Expand a record to view additional details.
- Select records to enable the submit action and row actions.
- Delete selected records; remaining records are renumbered.
- Open an edit dialog for a selected record.

## Files

- `index.html` contains the page structure.
- `styles.css` contains the page styles.
- `app.js` contains the record data and interactions.
